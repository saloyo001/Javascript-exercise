primitive data types are the basic types of data that a programming language uses to store simple values. 
They are called primitive because they are the most fundamental building blocks for handling data in a program.


1. String – Used to store text, such as names or messages.

2. Number – Used to store numeric values, including whole numbers and decimals.


3. BigInt – Used to store very large whole numbers that cannot be safely represented by the regular Number type.


4. Boolean – Used to store one of two values: true or false.


5. Undefined – Represents a variable that has been declared but has not yet been assigned a value.


6. Null – Represents the intentional absence of a value.

7. Symbol – Used to create unique identifiers, often for object properties.

Loose equality (==) compares two values after performing type conversion if their data types are different.

Strict equality (===) compares both the values and their data types without performing type conversion.

A truthy value is any value that JavaScript treats as true, 
while a falsy value is a value that JavaScript treats as false.
Falsy values include false, 0, "" (an empty string), null, undefined, NaN, -0, and 0n. 
All other JavaScript values are generally considered truthy

The strict equality operator (===) is generally recommended over the loose equality operator (==) in JavaScript if statements
because === compares both the value and the data type without changing the type of the values.
In contrast, == uses type coercion, which means JavaScript automatically converts one value to another data type before comparing them.
