q2 part 1.
primitive data types are the basic types of data that a programming language uses to store simple values. 
They are called primitive because they are the most fundamental building blocks for handling data in a program.


1. String – Used to store text, such as names or messages.

2. Number – Used to store numeric values, including whole numbers and decimals.


3. BigInt – Used to store very large whole numbers that cannot be safely represented by the regular Number type.


4. Boolean – Used to store one of two values: true or false.


5. Undefined – Represents a variable that has been declared but has not yet been assigned a value.


6. Null – Represents the intentional absence of a value.

7. Symbol – Used to create unique identifiers, often for object properties.

q3 part 1.
Loose equality (==) compares two values after performing type conversion if their data types are different.

Strict equality (===) compares both the values and their data types without performing type conversion.

q1 part1
A truthy value is any value that JavaScript treats as true, 
while a falsy value is a value that JavaScript treats as false.
Falsy values include false, 0, "" (an empty string), null, undefined, NaN, -0, and 0n. 
All other JavaScript values are generally considered truthy

With the && operator, JavaScript stops when it finds a falsy value, because the whole expression cannot be true if one condition is false. 
With the || operator,JavaScript stops when it finds a truthy value, because the whole expression is already true.


q3 part1
The strict equality operator (===) is generally recommended over the loose equality operator (==) in JavaScript if statements
because === compares both the value and the data type without changing the type of the values.
In contrast, == uses type coercion, which means JavaScript automatically converts one value to another data type before comparing them.

 The initialization runs once at the beginning of the loop and is usually used to create and set the starting value of a counter. 
 The condition is checked before each iteration to determine whether the loop should continue.

 q2 part2
 A loop invariant is a condition that remains true throughout the execution of a loop. 
 To ensure a while loop terminates, the programmer must update the variables in the loop so that the condition eventually becomes false, preventing an infinite loop.

 q3 part2
 The break keyword immediately terminates a loop, while continue skips the rest of the current iteration and moves to the next one.
  break stops the loop entirely, whereas continue allows it to keep running. 
  In a for loop, continue still allows the final-expression to execute, updating the counter before the next iteration.

  A Function Declaration is a function defined using the function keyword and a name, while a Function Expression is a function stored in a variable. 
  Function declarations are hoisted, meaning they can be called before they are defined in the code. 
  Function expressions assigned to variables cannot generally be called before the variable is initialized.

  q2 part3
  The arguments object is an array-like object that contains all arguments passed to a traditional function. 
  The Rest Parameter (...args) collects multiple arguments into a real array. 
  Rest parameters are preferred in modern JavaScript because they are easier to use and support array methods.


  q3 part3
  When a return keyword is used without a value, the function immediately stops executing and returns undefined. 
  Any code written after the return statement in that execution path will not run.
